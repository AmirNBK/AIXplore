# AIXplore

A modern frontend project built with Next.js, React, TypeScript, and Tailwind CSS.

## Overview

AIXplore is a personal frontend project focused on building a polished, component-based web experience with a modern Next.js architecture.

## Tech Stack

- Next.js 14
- React 18
- TypeScript
- Tailwind CSS
- ESLint

## Project Structure

The project uses a structured `src` directory with separate application, component, and asset areas to keep the frontend organized and maintainable.

## Getting Started

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open `http://localhost:3000` in your browser.

## Build

```bash
npm run build
npm start
```
